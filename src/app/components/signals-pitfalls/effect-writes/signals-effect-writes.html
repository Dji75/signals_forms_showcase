⚠️ Écritures interdites dans les effets (Anti-pattern)

Tenter de modifier un signal d'écriture (Writable Signal) à l'intérieur d'un effet ou d'un calcul réactif (computed) is a bad practice. Par défaut, Angular v19+ lève une exception NG0600 pour empêcher cela.

DÉFENSE DE CONCEPTION

NG0600 & Flux Unidirectionnel

❌ RuntimeError: NG0600: Writing to signals is not allowed in a `computed` or an `effect` by default.

Pourquoi cette interdiction ?

Autoriser les écritures dans les effets crée des risques élevés de boucles infinies (l'effet écrit dans un signal S1, qui déclenche un autre effet qui réécrit dans un signal S2, qui redéclenche le premier effet...). Cela détruit aussi le principe du flux d'état unidirectionnel.

❌ À éviter (Effet synchronisateur) :
effect(() => {
  const quantite = this.qty();
  // Interdit et lève NG0600 :
  this.prixTotal.set(quantite * 15); 
});
✅ Solution recommandée (Signal calculé) :
// Purement réactif et sans effet de bord :
prixTotal = computed(() => this.qty() * 15);
