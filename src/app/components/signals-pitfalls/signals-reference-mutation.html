⚠️ Mutation directe d'objets (Comparaison par Référence)

Par défaut, un signal utilise l'égalité stricte (===) pour décider s'il doit propager un changement. Si vous modifiez un attribut d'un objet en place sans changer la référence de l'objet, Angular considère que l'état n'a pas changé.

PIÈGE RÉFÉRENCE

Immuabilité & Références de données

Signal userObj() (État interne brut) : 
{{ userObj() | json }}
Signal dérivé userDescription() :
{{ userDescription() }}
💡 Constat :
  • Le bouton rouge incrémente l'âge de l'objet mais conserve la même référence mémoire. Bien que le JSON se mette à jour (car le template réévalue tout le composant), le signal calculé userDescription() ne se met PAS à jour car pour lui, l'objet n'a pas changé !
  • Le bouton vert retourne une nouvelle copie de l'objet (via { ...u }), provoquant instantanément le recalcul du signal dérivé.
